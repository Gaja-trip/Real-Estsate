# 공인중개사 민법 기출 CBT

공인중개사 기출문제를 PDF 옆 답안지 방식이 아니라, 문제와 선택지를 한 문항씩 보여주는
CBT 방식으로 풀 수 있는 설치형 웹앱입니다.

## 공개 웹페이지

https://gaja-trip.github.io/Real-Estsate/

`main` 브랜치가 갱신되면 GitHub Pages에 자동 배포됩니다.

## 첫 번째 CBT 세트

- 2021년 제32회 공인중개사 1차 1교시 B형
- 민법 및 민사특별법 41번~80번, 총 40문항
- 2021년 공식 최종정답 기준 채점
- 76번 전항 정답 인정 처리

## 가능한 기능

- 문제와 5개 선택지를 한 문항씩 표시
- 이전·다음 및 전체 문제 번호 이동
- 답안 선택, 변경, 보류 표시
- 진행률과 경과 시간 확인
- 답안과 현재 위치 자동 저장
- 제출 후 즉시 채점
- 정답·오답·미응답 표시
- 영역별 결과와 다시 볼 문제 이동
- 키보드 단축키(1~5, 좌우 방향키, F)
- 연도별 Q-Net 공식 기출 자료 검색
- 브라우저 설치형 앱(PWA) 및 오프라인 이용

## 실행 방법

### 가장 쉬운 방법

`start_app.bat`를 실행합니다.

- 주소: `http://127.0.0.1:4173`

### 수동 실행

```bash
node server.js
```

그 다음 `http://127.0.0.1:4173`을 엽니다.

## 주요 파일

- `index.html`: CBT 화면
- `styles.css`: 반응형 UI 스타일
- `app.js`: 문제 이동, 저장, 채점, 오답 검토 로직
- `public/data/civil-law-2021.js`: 2021년 민법 40문항 구조화 데이터
- `manifest.webmanifest`, `sw.js`: 설치 및 오프라인 캐시
- `public/pdfs/`: 원문 대조용 문제지와 공식 정답

## 자료 출처

문항과 정답은 한국산업인력공단 Q-Net의 2021년 제32회 공인중개사 자격시험
문제지 및 공식 최종정답을 기준으로 정리했습니다.
