# 공인중개사 기출 풀이 앱

PDF 문제지를 보면서 답안을 입력하고 바로 채점할 수 있는 설치형 웹앱입니다.

## 공개 웹페이지

https://gaja-trip.github.io/Real-Estsate/

`main` 브랜치가 갱신되면 GitHub Pages에 자동 배포됩니다.

## 현재 포함된 자료

- 2021년 제32회 공인중개사 자격시험 1차 1교시 B형 문제지
- 2021년 제32회 공인중개사 자격시험 공식 정답 PDF
- 2024년 제35회 공인중개사 자격시험 최종정답 PDF
- Q-Net 공식 자료실의 2005년 제15회 추가시험부터 2025년 제36회까지 문제지 및 최종정답 링크

## 현재 가능한 기능

- 2021년 제32회 1차 1교시 B형 80문항 풀이
- 공식 정답 기준 즉시 채점
- 오답 확인
- 진도 자동 저장
- 연도 또는 회차로 Q-Net 기출문제 검색
- 브라우저 설치형 앱(PWA) 지원
- 국가법령정보센터 바로가기 메뉴 제공

## 실행 방법

### 가장 쉬운 방법

`start_app.bat` 실행

- 미니 서버를 띄운 뒤 브라우저에서 앱을 엽니다.
- 주소: `http://127.0.0.1:4173`

### 수동 실행

```bash
node server.js
```

그 다음 브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:4173
```

## 파일 구성

- `index.html`: 메인 화면
- `styles.css`: UI 스타일
- `app.js`: 문제풀이/채점 로직
- `manifest.webmanifest`: 설치형 앱 설정
- `sw.js`: 오프라인 캐시
- `server.js`: 정적 파일 서버
- `public/pdfs/2021-question.pdf`: 2021 문제지
- `public/pdfs/2021-answer.pdf`: 2021 정답표
- `public/pdfs/2024-answer.pdf`: 2024 최종정답

## 참고

- 현재 앱에서 자동 채점되는 세트는 `2021년 제32회 1차 1교시 B형`입니다.
- 사용자가 제공한 파일 두 개는 서로 다른 연도 자료라서, 2021 문제지를 실제 채점 가능하게 하기 위해 2021 공식 정답 PDF를 추가로 확보해 포함했습니다.
